# Dark Forest (Godot 4)

A first-person 3D horror-exploration game, made solo in Godot 4.7.
I started it from a tutorial to learn 3D game dev, and I'm now expanding it
using my own design document.

📄 **[Read the Game Design Document](GDD.md)**

## Built so far
- First-person movement with mouse look
- Sword attack with cooldown
- Enemy AI with a state machine (Idle → Chase → Attack → Die)
- Enemy pathfinding with NavigationAgent3D
- Enemy respawner on a timer
- HUD with HP bar and gold counter

## Planned (from my GDD)
- **Flashlight system** as the core tension mechanic
- **Ghost** enemy: charges on sight, stopped by looking away
- **Zombie** enemy: stunned briefly by the flashlight
- Walk / run / crouch with noise that attracts enemies
- Huts to loot, keys, and a locked house with a secret

## Built with
Godot 4.7, GDScript

## Controls
- Move: W A S D · Look: Mouse · Jump: Space · Attack: Left mouse button
